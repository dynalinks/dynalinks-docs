All endpoints live under this base URL:

```
https://dynalinks.app/api/v1
```

Requests are authenticated with your project's API key, sent as `Authorization: Token <key>`. See [API authorization](/api/authorization) for how to create a key.

The OpenAPI spec this reference is built from is public at [`https://dynalinks.app/api/v1/openapi.json`](https://dynalinks.app/api/v1/openapi.json). Import it into Postman, Insomnia or a client generator.

## Endpoints

- [Links](/reference/links/list-links): create, update, look up and delete dynamic links.
- [Short links](/reference/short-links/create-short-link): shorten long URLs and resolve short links.
- [iOS apps](/reference/ios-apps/list-ios-apps): manage the iOS apps that links open.
- [Android apps](/reference/android-apps/list-android-apps): manage the Android apps that links open.
- [API keys](/reference/api-keys/list-api-keys): manage a project's API keys. Requires a **master API key**.
- [Projects](/reference/projects/list-projects): manage projects. Requires a **master API key**.
- [Page templates](/reference/page-templates/get-page-template): manage the page template shown on link preview pages. Requires page-template access for the project, and is still experimental.
