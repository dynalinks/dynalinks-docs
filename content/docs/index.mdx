Welcome to the [Dynalinks](https://dynalinks.app) documentation!  
[Dynalinks](https://dynalinks.app) is a lightweight, privacy-first deep linking platform that helps developers and marketers create short, flexible links for mobile apps. It supports advanced use cases like deferred deep linking and platform-specific redirects, without compromising on user data privacy.

Use this documentation to learn how to:
- Integrate with mobile platforms using our [iOS SDK](/integrations/ios-sdk.html), [Android SDK](/integrations/android-sdk.html), [Flutter SDK](/integrations/flutter-sdk.html), or [React Native SDK](/integrations/react-native-sdk.html)
- Handle deferred deep linking for users who install your app after clicking a link
- Track and attribute installs and clicks with optional analytics
- Set up fallback behavior and customize redirects

Whether you're building for marketing teams or integrating deep links directly into your app, Dynalinks is designed to get you up and running in minutes.
